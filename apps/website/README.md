# 网站应用

> **维护范围** 开发入口、页面接入方式或数据解释规则变化时，更新本文。仅调整布局、按钮位置或图片展示顺序时，无需更新。

络米星集的网站应用，提供图鉴浏览、筛选、详情及友邻资料查询。使用 React、TanStack Start / Router、Tailwind CSS 与 shadcn/ui，通过 Vite+ 开发和构建，部署到 Cloudflare Workers。依赖版本以 [package.json](package.json) 和[工作区配置](../../pnpm-workspace.yaml)为准。

## 安装网页应用

从侧栏底部选择「安装应用」，按浏览器提示或对应平台的指引完成安装。安装后查询资料仍需联网。

## 本地开发

依赖安装与资源准备见[根 README](../../README.md#本地开发)，环境文件规则也由根 README 维护。命令在仓库根目录执行：

```bash
vp run website#dev
```

实际访问地址以启动输出为准；根目录的 `vp run dev` 调用同一入口。

## 名称搜索

在当前列表中可按名称片段、拼音或首字母搜索，例如用 `fanqie` 或 `fq` 查找「番茄」。复制列表地址可分享当前筛选和视图。地址未指定布局时，列表沿用浏览器中保存的偏好。

## 代码结构

业务改动从 [features](src/features/) 入手，[routes](src/routes/) 负责路由接线；资源读取等基础设施在 [infrastructure](src/infrastructure/)，通用组件在 [ui](src/ui/)，资源验证与预览工具在 [scripts](scripts/)。自动生成的路由树不手工编辑。

新列表由所属领域提供查询结果、筛选控件、表格列和卡片内容，交给[共享列表](src/features/list-page/)渲染。物品概览先列常用标签与所属集合，再列该类物品的基本资料和专属信息。例如菜肴先列难度、解锁条件和炊具，再展示食用效果；生物先列学名和尺寸，再展示出没条件。通用信息中的「筛选标签」字段提供该物品的全部标签筛选入口，收录边界见[标签筛选策略](docs/tag-filter-policy.md#物品详情)。需要比较候选、查用量或按顺序阅读的内容进入单层目录，例如配方、生长阶段和用途清单。字段和章节的位置由用途决定，同类信息有多条时仍在原处展示。只有概览时隐藏目录，仍可切换关联条目。

React、组件引入与测试范围遵循[Agent 协作约定](../../AGENTS.md)。

概览字段按值的含义选择文本、数量与范围、条件与提示、分类标签、友邻头像、关联条目、效果明细或购买报价。多值沿用同一类型。单行字段至少 32px，正文行高 24px，字段名与首行中心对齐；较长的提示、效果和报价按内容换行。分类标签和关联条目小图高 24px，友邻使用 32px 的透明头部小像。悬停或键盘聚焦头像显示姓名，缺图时直接显示可跳转的姓名。

## 数据与资源

[资源读取器](src/infrastructure/resources.ts)按网站资源清单加载并校验领域文档。功能模块按[共享数据契约](../../packages/schema/README.md)读取数据，标签的可见性、分组和命名由[标签筛选策略](docs/tag-filter-policy.md)维护。

通用物品关联视图的 `browsable` 只控制该视图中的浏览与链接。例如，友邻服饰在该视图中没有链接，仍是有独立详情的正式物品。收录范围见[领域术语表](../../GLOSSARY.md#收录与图鉴)。

物品概览按商店列出每次购买的配置报价，并保留货币、价格条件和店铺支付说明。同店同币种的不同金额分别展示。商品是否实际在售取决于游戏进度和店铺状态。

图鉴详情的所属套组、套装或系列以集合明确列出的成员为准。关联物品导航还可以包含种子、果实和对应款式。植株通过自身的生长阶段关联种子，通过收获物记录关联作物或花朵。家具配方分别标出创想卡的来源树木和所属卡集的获取提示，方便区分掉落的卡片、卡集与制作出的家具。

收获物概览列出关联种子、来源植株与成熟形态。成熟形态与来源植株在编号、名称和图片上都相同时，只列来源植株；多种种子共有的成熟形态只展示一次，保留各自的生长阶段入口。单品的花色与颜色标签同名时，共用一个花色值和对应的筛选入口。

物品概览按「喜爱」「好感」「反感」分别列出点名此物品的友邻，仅显示有记录的等级。头像直接链接到该友邻对应的偏好。按标签给出的偏好可在友邻详情查看。「星屿探索提示」按物品 ID 对应星屿的生物或特产提示，并标出各区域的常规探索和邂逅候选。实际产出受探索条件影响。

花朵的「用于染发」分列单花可匹配的色系和可配对的花朵，可跳到适用发型查看各区域的默认色、可选色系与配置费用。未配置费用与已知金额分别显示。小栖地概览展示获取提示，任务指定地点在布景要求中单独注明，数量沿用游戏界面的显示值。

生物概览的「关联小栖地」对应布景的关联生物名单。「小栖地用途」章节列出物品能满足的摆放或承载要求，与小栖地详情使用相同的家具尺寸条件。客户端示例和插图只供摆放参考，绘制空间视图需要可确认的坐标、朝向与承载关系。

更新网站资源和生产资源地址见[CI/CD 与部署](../../DEPLOYMENT.md#资源更新流程)。

## 常用检查

在仓库根目录运行 `vp run website#test` 执行网站非 UI 测试，运行 `vp run website#build` 构建网站。页面交互需人工验收。

校验本地或已发布资源时，按[发布契约检查](docs/release-checks.md#运行方式)选择命令。提交前检查见[贡献指南](../../CONTRIBUTING.md#提交-pr)，发布前验证见[CI/CD 与部署](../../DEPLOYMENT.md#正式发布)。
