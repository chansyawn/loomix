# 全部页标签筛选策略

「全部」页的标签树由人工维护的策略裁剪，避免把内部 gameplay tags 直接暴露给用户。策略文件为 [`apps/website/src/features/all/tag-filter-policy.ts`](../apps/website/src/features/all/tag-filter-policy.ts)，修改后需同步本文档与资源更新检查。

## 白名单

只展示以下 13 个根标签：

```text
颜色、材质、艺术风格、家具、服装、生物、食物、食材、尺寸、产区分类、烹饪原料、素材、手持物
```

白名单使用 `internalName` 维护，不使用可能随快照变化的标签 ID。

## 可见性

- 根标签必须在白名单中。
- 标签必须被至少一条正式物品的 `tagIds` 直接引用，或拥有可见子级。
- 引用标签的祖先路径保留；没有可见标签的白名单根整个隐藏。
- 集合记录（套装、系列）不参与可见性判断，与「全部」页的数据范围一致。
- 不加载 `neighbors.json`。只被友邻喜好引用的标签（例如“肥料”）不会出现在树中；友邻页对应链接进入「全部」页后会被静默忽略，不产生筛选或 chip。

## 中文名清理

筛选树和 chip 使用统一的名称解析顺序：

1. `internalName` 显式特例；
2. 去掉 `食材_`、`容器_`、`食物_` 前缀，前缀同时作用于 `displayName`；
3. 使用官方 `displayName`；
4. 回退到 `internalName`。

当前显式特例：

| `internalName` | 显示名   |
| -------------- | -------- |
| 产区分类       | 产区     |
| 种植作物分类   | 作物分类 |
| 生物移动模式   | 移动方式 |
| 鱼版型分类     | 鱼体型   |
| 生物花纹       | 花纹     |
| 活动时间       | 活跃时间 |
| 赶海生物特征   | 赶海特征 |
| 含水果父级     | 含水果类 |
| 含谷物父级     | 含谷物类 |
| 含蔬菜父级     | 含蔬菜类 |
| 含海鲜父级     | 含海鲜类 |
| 容器_水果      | 水果容器 |
| 食材_颜色      | 颜色分类 |
| Diy素材        | DIY 材料 |
| 手部饰品       | 手部配饰 |

- 允许不同分支存在同名标签，例如“食材”和“生物”下都可能有“草莓”；chip 使用完整路径区分。
- 同一父级下不允许重名，校验脚本会报错。
- 清理只作用于「全部」页的标签树与 chip，不改变详情页、类别页或其他数据展示。

## 资源更新检查

每次更新 `resources/website/` 后必须执行：

```bash
vp run --no-cache website#verify-tag-filter
```

脚本会检查：

- 13 个白名单根是否仍然存在；
- 显式特例指向的 `internalName` 是否仍然存在；
- 白名单根是否仍有可见标签；
- 可见标签是否仍含 `_` 或“父级”；
- 是否出现同级重名。

脚本失败时，根据报告更新策略文件：

1. 根标签被重命名或新增品类：更新 `TAG_FILTER_ROOT_NAMES`。
2. 新增内部前缀：加入 `TAG_LABEL_PREFIXES`，确认不会造成同级重名。
3. 新增结构名或重名标签：加入 `TAG_LABEL_OVERRIDES`。
4. 更新本文档的清单。

检查通过后仍需运行：

```bash
vp check
vp run -r test
vp run website#build
```

并人工打开「全部」页，确认筛选树、搜索、AND/OR、chip 移除和友邻标签链接行为正常。
